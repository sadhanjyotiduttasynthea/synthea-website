05/FAQFAQ

Questions, answered.

Ask us directly
Can simulation replace physical testing?

Simulation reduces the number of tests and helps focus them, but it does not remove the need for validation. We are explicit about model assumptions and uncertainty.

What do you need to set up a simulation?

Geometry (CAD or drawings), materials, operating conditions and the question you want answered. Measurement data is valuable for validation.

Which simulation software do you use?

Tools are selected according to the physics and the project. We will discuss the approach and deliverables during scoping.

What does a simulation deliverable look like?

Typically a technical report with the model description, assumptions, results, visualizations and recommendations.
